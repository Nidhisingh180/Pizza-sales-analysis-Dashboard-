🍕 Pizza Sales Analytics Dashboard
1. Project Title / Headline

📊 Pizza Sales Analytics Dashboard (Excel + SQL Project)

An interactive sales analytics dashboard created using Microsoft Excel and SQL to analyze pizza sales performance, customer ordering behavior, and business trends. The project transforms raw sales data into meaningful insights through KPIs, charts, and trend analysis.

2. Short Description / Purpose

The Pizza Sales Dashboard is an Excel-based data analytics project designed to monitor and evaluate pizza sales performance. It helps analyze revenue trends, customer ordering patterns, best-selling pizzas, peak sales timings, and category-wise performance using interactive charts, pivot tables, and SQL analysis.

3. Tech Stack

The project was built using the following tools and technologies:

🗄️ SQL Server Management Studio (SSMS) – Used for querying and analyzing pizza sales data using SQL.
📑 Microsoft Excel – Used for data cleaning, preprocessing, KPI creation, and dashboard development.
📊 Excel Charts & Pivot Tables – Used for creating interactive visualizations and trend analysis.
📂 SQL Queries – Used for extracting business insights and performing sales analysis.
📁 File Formats – .xlsx, .sql, and .png.
4. Data Source

Source: Sample Pizza Sales Dataset

The dataset contains transactional pizza sales records including:

Pizza categories and sizes
Order dates and order timings
Quantity sold
Revenue generated
Total orders
Best and worst-selling pizzas
Daily and hourly sales trends

Data cleaning and preprocessing were performed using Excel and SQL before creating the final dashboard and visual reports.

5. Features / Highlights
• Business Problem

Pizza businesses generate large volumes of transactional sales data daily. However, raw data alone makes it difficult to quickly identify:

Best-selling pizzas
Peak order timings
Customer ordering patterns
High-performing categories
Underperforming menu items

Without proper analysis, businesses may struggle with inventory planning, staffing decisions, and sales optimization.

• Goal of the Dashboard

The dashboard was designed to:

Track overall sales performance
Analyze customer ordering behavior
Identify top and bottom-selling pizzas
Monitor hourly and daily sales trends
Compare pizza categories and sizes
Provide data-driven business insights
